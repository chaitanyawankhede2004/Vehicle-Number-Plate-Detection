# Digital Image Processing

A collection of Digital Image Processing (DIP) programs and experiments demonstrating fundamental image processing concepts such as image enhancement, filtering, edge detection, segmentation, histogram processing, and frequency-domain analysis.

---

## 📌 Overview

This repository contains practical implementations of various Digital Image Processing techniques used in computer vision, image analysis, and signal processing. The projects are designed for learning, experimentation, and academic purposes.

## 🎯 Objectives

- Understand fundamental image processing concepts.
- Learn image enhancement and restoration techniques.
- Explore spatial and frequency domain operations.
- Implement edge detection and segmentation methods.
- Gain hands-on experience with image processing tools and algorithms.

---

## 🛠️ Technologies Used

- MATLAB
- Python
- OpenCV
- NumPy

- Image Processing Toolbox

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/chaitanyawankhede2004/Digital-Image-Processing.git
cd Digital-Image-Processing
```

### Running MATLAB Programs

1. Open MATLAB.
2. Navigate to the required program folder.
3. Open and run the desired `.m` file.

### Running Python Programs

Install dependencies:

```bash
pip install opencv-python numpy matplotlib
```

Run a program:

```bash
python filename.py
```
